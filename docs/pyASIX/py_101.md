# Estructures de Dades (Llistes i Tuples)

Fins ara hem guardat informació en variables "_individuals_": **una variable per a un nom**, **una per a una IP** o **una per a un espai de disc**.

Però en la vida real d'un _SysAdmin_, no gestionem un sol usuari o un sol servidor; gestionem **llistats** de coses: **50 usuaris** de l'institut, **10 servidors** de la xarxa o **una llista de fitxers de log** que cal esborrar.

Per no haver de crear 50 variables diferents (`usuari1`, `usuari2`, `usuari3`, ...), utilitzem _Llistes_ i _Tuples_.

## 1. Les Llistes (Mutables / Modificables)

Una **llista** és una c**ol·lecció ordenada d'elements** separats per comes i tancats entre corxets (`[` i `]`).

```py
# Una llista de noms d'usuaris del sistema
usuaris_asix = ["marta", "pau", "laura", "jordi"]

# Una llista amb els ports més comuns de servidors web
ports_web = [80, 443, 8080]
```

### Com accedim als elements? (L'Índex)

En informàtica, sempre **comencem a comptar des de 0**. El primer element de la llista és a la posició `#!py [0]`.

```py
servidors = ["srv-web", "srv-db", "srv-backup"]

print(servidors[0])  # Mostra: srv-web (El primer!)
print(servidors[1])  # Mostra: srv-db  (El segon!)
```

!!!tip "Si volem agafar l'últim element d'una llista..."

    ... sense saber quants n'hi ha en total, podem fer servir l'índex negatiu `#!py [-1]`:

    ```py
    print(servidors[-1]) # Mostra: srv-backup (L'últim de tots)
    ```

### Modificar i afegir elements

Les llistes són **mutables**, la qual cosa vol dir que **podem canviar-ne el contingut**, afegir-hi coses noves o esborrar-ne durant l'execució de l'script.

* **Afegir un element al final (`#!py .append()`)**:

    ```py
    usuaris_asix.append("oriol")
    # Ara la llista és: ["marta", "pau", "laura", "jordi", "oriol"]
    ```

* **Esborrar un element (`#!py .remove()` o `#!py del`):**

    ```py
    usuaris_asix.remove("pau") # Cerca "pau" i l'elimina
    ```

    ```py
    del usuaris_asix[-1] # Elimina el darrer de la llista
    ```

    !!!error "En tots dos casos cal que existeixi l'element, sinó, dona error."

* **Saber quants elements té la llista (`#!py len()`):**

    ```py
    total_usuaris = len(usuaris_asix)
    print(f"Hi ha {total_usuaris} usuaris registrats.")
    ```

## 2. Les Tuples (Immutables / No es poden canviar)

Una tupla és molt similar a una llista, però té una diferència fonamental: **no es pot modificar mai** un cop s'ha creat (no podem afegir, treure ni canviar els seus elements). Se solen escriure **entre parèntesis** (``#!py (` i ``#!py )`).

!!!question "Per què la fem servir en lloc d'una llista?"

    * **Seguretat**: Ens assegura que ningú (ni un altre script, ni un error humà) modifiqui una dada crítica del sistema mentre s'executa el programa.

    * **Rendiment**: Python les gestiona de manera molt més ràpida a la memòria RAM.

```py 
# Si intentem canviar un valor d'una tupla:
config_base[0] = "192.168.1.1"  # ERROR! TypeError: 'tuple' object does not support item assignment
```

**Per tant, no existeix ni `#!py append`ni `#!py remove` en les tuples.**

## 3. Resum de diferències ràpid

| Característica | Llista (list) | Tuple (tuple) |
|:--------------|:--------------|:--------------|
| **Símbol** | Corxets `#!py [ ]` | Parèntesis `#!py ( )` |
| **Es pot modificar?** | Sí (Mutable) | No (Immutable) |
| **Ús típic a ASIX** | Llistats d'usuaris, fitxers a processar, IPs dinàmiques. | Configuracions fixes, parelles de coordenades o dades de connexió. |

## Pràctica guiada: Gestor de cua de tasques

Anem a veure un exemple bàsic on afegim una nova tasca de manteniment a la nostra llista de feines pendents de l'institut.

```py
print("--- SISTEMA DE GESTIÓ DE MANTENIMENT ---")

# Llista inicial de tasques
tasques = ["Actualitzar Ubuntu", "Comprovar disc de Backup"]

print(f"Tasques pendents actuals ({len(tasques)}):")
print(tasques)

# Demanem una nova tasca a l'administrador
nova_tasca = input("Introdueix una nova tasca per avui: ")

# L'afegim a la llista
tasques.append(nova_tasca)

print("\nLlista actualitzada de tasques:")
print(tasques)

print(f"La primera tasca que has de fer és: {tasques[0]}")
```

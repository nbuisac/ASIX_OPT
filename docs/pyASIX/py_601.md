# Fitxers de Text Pla (`.txt`, `.log`) i `.csv`

Fins ara, totes les dades que creàvem als nostres scripts desapareixien en tancar la terminal. Per crear eines d'administració útils, necessitem **persistència de dades**: la capacitat de llegir i escriure informació en fitxers del disc dur.

## 1. Treballar amb Fitxers de Text Pla (`.txt`, `.log`)

Per obrir un fitxer a Python fem servir la funció [`open()`][open]. Aquesta funció necessita dos paràmetres principals: la **ruta del fitxer** i el **mode d'obertura**.

### Modes d'obertura principals

| Mode | Descripció | Què fa si el fitxer NO existeix? |
| :---: | :--- | :--- |
| **`"r"`** | **Lectura** (*Read*). Mode per defecte. | Dóna un error (`FileNotFoundError`). |
| **`"w"`** | **Escriptura** (*Write*). Sobreescriu el contingut. | Crea un fitxer nou. Si ja existia, **el buida**. |
| **`"a"`** | **Afegir** (*Append*). Escriu al final del fitxer. | Crea un fitxer nou si no existeix. |

### La bona pràctica: La instrucció [`#!py with`][with]

Antigament s'obria un fitxer amb `f = open(...)` i calia recordar tancar-lo amb `f.close()`. Si l'script fallava entremig, el fitxer podia quedar corromput a la memòria.

Avui en dia, **SEMPRE fem servir la instrucció [`#!py with`][with]**. Python es tanca automàticament i de forma segura en sortir del bloc, de la mateixa manera que un bloc `#!py if` o `#!py for`.

```python
# Sintaxi moderna i segura:
with open("ruta/del/fitxer.txt", "mode", encoding="utf-8") as f:
    # Treballem amb el fitxer 'f'
```

!!! tip "Per què fem servir `#!py encoding='utf-8'`?"

    Especificar l'codificació UTF-8 evita problemes amb els accents, la 'ç' o caràcters especials tant en Linux com en Windows.

Lectura de Fitxers de Text

Segons la mida del fitxer, tenim diferents maneres de llegir-lo:

=== "Llegir línia a línia (`#!py for` - Recomanat per a Logs)"

    És la manera més eficient. No carrega tot el fitxer a la RAM, sinó que llegeix línia a línia (ideal per a fitxers de registres de gigabytes de mida).

    ```python
    with open("/var/log/syslog.log", "r", encoding="utf-8") as f:
        for linia in f:
            # .strip() elimina el salt de línia '\n' del final
            print(f"LÍNIA: {linia.strip()}")
    ```

=== "Llegir totes les línies en una Llista (`#!py .readlines()`)"

    Carrega totes les línies del fitxer en una **llista de cadenes de text**.

    ```python
    with open("usuaris.txt", "r", encoding="utf-8") as f:
        linies = f.readlines()
    print(f"El fitxer té {len(linies)} línies.")
    ```

=== "Llegir tot el text complet (`#!py .read()`)"
    
    Retorna tot el contingut del fitxer en una sola variable de text (str).

    ```python
    with open("missatge.txt", "r", encoding="utf-8") as f:
        contingut = f.read()
    print(contingut)
    ```

### Escriptura de Fitxers de Text

Per escriure dades en un fitxer fem servir el mètode `#!py .write()`.

!!!note "`#!py .write()` no afegeix automàticament un salt de línia"

    per tant hem d'afegir `\n` nosaltres mateixos.

```py
# Creem o sobreescriwim un fitxer de configuració
with open("servei.conf", "w", encoding="utf-8") as f:
    f.write("PORT=8080\n")
    f.write("MAX_CONNEXIONS=100\n")
    f.write("LOG_LEVEL=DEBUG\n")

# Afegim registres (Append) a un fitxer de log sense esborrar l'anterior
import datetime

ara = datetime.datetime.now()
with open("execucions.log", "a", encoding="utf-8") as f:
    f.write(f"[{ara}] Script executat correctament per l'usuari root.\n")
```

## 2. Fitxers Estructurats en Taula (.csv)

El format CSV (_Comma-Separated Values_) és l'estàndard per intercanviar taules de dades (com ara fulls de càlcul d'Excel, llistes d'usuaris o exportacions de bases de dades).

Tot i que podríem llegir un CSV com a text pla separant per comes amb `#!py .split(",")`, Python inclou el mòdul oficial `csv`, que gestiona automàticament cometes, caràcters especials i diferents separadors (com la coma `,` o el punt i coma `;`).

```py
import csv
```

### Lectura de fitxers CSV

Tenim dues eines principals per llegir un fitxer CSV:

=== "Com a Llistes (`#!py csv.reader`)"
    
    Cada fila del CSV es converteix en una llista de cadenes de text.

    ```python
    import csv
    with open("usuaris.csv", "r", encoding="utf-8") as f:
        lector = csv.reader(f, delimiter=",")
    
        # Opcional: saltem la primera línia si conté les capçaleres
        capcalera = next(lector)
        print(f"Columnes: {capcalera}")
        
        for fila in lector:
            # fila és una llista: ["nom", "uid", "shell"]
            print(f"Usuari: {fila[0]} | UID: {fila[1]}")
    ```

=== "Com a Diccionaris (`#!py csv.DictReader` - Recomanat)"

    Converteix cada fila en un Diccionari, fent servir els noms de les columnes de la primera línia com a claus. És molt més net i intuïtiu.

    ```python
    import csv
    with open("servidors.csv", "r", encoding="utf-8") as f:
        lector_dict = csv.DictReader(f, delimiter=";")

        for fila in lector_dict:
            # fila és un diccionari: {"hostname": "...", "ip": "...", "ram": "..."}
            print(f"Servidor: {fila['hostname']} té la IP {fila['ip']}")
    ```

### Escriptura de fitxers CSV

Per guardar dades en format CSV, també podem fer servir diccionaris amb `#!py csv.DictWriter`, especialment útil quan tenim una llista de diccionaris a Python i la volem exportar a un fitxer.

```py
import csv

# Llista de diccionaris amb dades de xarxa
equips = [
    {"hostname": "pc-lab-01", "ip": "192.168.1.101", "vlan": 10},
    {"hostname": "pc-lab-02", "ip": "192.168.1.102", "vlan": 10},
    {"hostname": "srv-nas", "ip": "192.168.1.200", "vlan": 20}
]

# Definim els noms de les columnes de la capçalera
camps = ["hostname", "ip", "vlan"] # o bé list(equips[0].keys())

with open("inventari_xarxa.csv", "w", newline="", encoding="utf-8") as f:
    escriptor = csv.DictWriter(f, fieldnames=camps, delimiter=";")
    
    # Escriure la primera línia amb els noms de les columnes
    escriptor.writeheader()
    
    # Escriure totes les files
    escriptor.writerows(equips)

print("Fitxer 'inventari_xarxa.csv' generat amb èxit!")
```

!!! note "El paràmetre `#!py newline=''`"

    Quan escrivim un fitxer CSV a Windows, és molt important afegir `#!py newline=''` a la funció `#!py open()`. En cas contrari, Python introduirà línies en blanc addicionals entre cada fila.

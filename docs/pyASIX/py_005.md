# Els Condicionals: Ensenyem el nostre programa a decidir

Fins ara, els nostres scripts s'executaven de dalt a baix, línia per línia, sense saltar-se'n cap. Però a la vida real d'un ordinador, les coses no sempre fan el mateix camí.

* Si la contrasenya és correcta, entrem al sistema; si no, ens diu "**Accés denegat**".

* Si ens queda menys d'un 10% de bateria, mostrem un _avís de color vermell_.

Per aconseguir que el nostre codi prengui camins diferents segons la situació, utilitzem els condicionals.

## 1. L'estructura bàsica: `#!py if` i `#!py else`

En Python, per dir-li "**Si passa això...**" utilitzem la paraula [`#!py if`][if] (que significa **_si_** de condició en anglès), i per dir "**si no...**" utilitzem `#!py else`.

Mirem aquest exemple on comprovem si l'usuari ha escrit bé una contrasenya d'accés de seguretat:

```py
# Demanem la paraula secreta de l'administrador
contrasenya = input("Introdueix la clau d'accés: ")

# Comparem la paraula secreta de l'administrador amb la de veritat
if contrasenya == "1234":
    print("Accés concedit. Benvingut/da, administrador/a.")
else:
    print("ALERTA: Contrasenya incorrecta. Accés denegat!")
```

### El secret més important de Python: Els dos punts (`#!py :`) i la indentació

Si us fixeu en el codi de dalt, hi ha dues normes de Python que mai us podeu saltar:

* **Els dos punts (`#!py :`)**: Sempre van al final de la línia del [`#!py if`][if] i del `#!py else`. Li diuen a Python: "Compte, que ara comença el bloc d'instruccions".

* **La indentació (el marge a l'esquerre)**: Les línies de dins de l'accés concedit o de l'alerta tenen quatre espais cap a la dreta (o un salt de tabulador). Això és vital. Python utilitza aquest espai per saber quines instruccions s'executen només si es compleix la condició, i quines s'executen sempre.

## 2. Com comparem coses? (Operadors de comparació)

Per fer preguntes a les condicions del [`#!py if`][if], utilitzem uns símbols especials que comparen valors. Aquí teniu els més habituals per a la terminal:

| Símbol | Què significa? | Exemple en codi |
|:------:|:---------------|:----------------|
| == | És igual a... | `#!py if usuari == "admin":` |
| != | És diferent de... | `#!py if estat != "actiu":` |
| < | És menor que... | `#!py if temperatura < 20:` |
| > | És major que... | `#!py if espai_lliure > 80:` |


!!!danger"No confongueu un sol igual (=) amb dos iguals (==)."

    * Un sol `#!py =` serveix per guardar informació en una variable (assignar).

    * El doble `#!py ==` serveix per comparar si dues coses són iguals.


## 3. Què passa si hi ha més de dues opcions? (`#!py elif`)

A vegades no és només "blanc o negre". Què passa si volem comprovar t**res nivells diferents** d'espai al nostre disc dur? Per afegir condicions intermèdies, utilitzem `#!py elif` (abreviació de _`#!py else if`_):

```py
# Demanem quants gigabytes de memòria tenim lliures
espai_disc = int(input("Quants GB de disc lliures et queden a l'ordinador?: "))

if espai_disc < 5:
    print("NIVELL CRÍTIC: No pots instal·lar cap programa més!")
elif espai_disc < 20:
    print("Atenció: L'espai de disc comença a ser baix.")
else:
    print("Tens prou espai. Tot correcte!")
```

## 4. Pràctica guiada: Comprovar els privilegis d'instal·lació

Anem a crear un petit assistent que demani el nom d'un usuari i decideixi si el sistema el pot reconèixer com a "_Superusuari_" (amb poder per esborrar fitxers clau de l'ordinador) o com a "_Usuari estàndard_".

```py
print("--- SISTEMA DE CONTROL DE PRIVILEGIS ---")

nom = input("Escriu el teu nom d'usuari de l'ordinador: ")

if nom == "root" or nom == "administrator":
    print("Atenció: Has entrat amb privilegis de Superusuari.")
    print("Pots fer canvis al sistema operatiu.")
else:
    print("Has entrat com a usuari comú.")
    print("No tens permisos per instal·lar programes.")

print("Script finalitzat amb èxit.")
```

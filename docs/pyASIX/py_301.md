# El Bucle [`#!py while`][while] i la Validació d'Entrada

A diferència del bucle [`#!py for`][for] (que **s'executa un número conegut de vegades** o **sobre una llista tancada**), el bucle **[`#!py while`][while] s'executa mentre una condició sigui certa (_True_)**.

**No sabem quantes vegades es repetirà**: pot ser cap vegada, 3 vegades o infinitament fins que l'usuari faci el que li demanem.

```py
# Sintaxi bàsica:
while condició_sigui_certa:
    executa_aquest_codi
```

## 1. El cas d'ús estrella: Validar l'entrada de dades

Fins ara, si demanàvem a l'usuari una nota entre 0 i 10 i escrivia -5 o 99, l'script continuava com si res o fallava. Amb un bucle `#!py while` podem "_atrapar_" l'usuari en un bucle fins que introdueixi una dada vàlida.

```py hl_lines="5"
# Volem que l'usuari introdueixi un port vàlid (entre 1 i 65535)
port = int(input("Introdueix un port de xarxa (1-65535): "))

# Mentre el port sigui incorrecte, tornem a demanar-ho
while port < 1 or port > 65535:
    print("ERROR: El port ha de ser un número entre 1 i 65535!")
    port = int(input("Torna a intentar-ho: "))

print(f" Port {port} acceptat correctament.")
```

!!!tip "La clau del `#!py while`"

    La condició del `#!py while` defineix què és el que està MALAMENT (la dada no vàlida), perquè volem que el bucle es repeteixi mentre l'usuari s'equivoqui.

## 2. El patró "Menú d'Opcions" (Bucle amb `#!py break` o Flag)

Un altre ús imprescindible és crear menús interactius per a eines d'administració que no es tanquin fins que l'usuari triï l'opció de "Sortir".

```py hl_lines="3"
opcio = ""

while opcio != "3":
    print("\n--- MENÚ D'ADMINISTRACIÓ DE SERVIDORS ---")
    print("1. Veure l'estat del disc")
    print("2. Reiniciar servei Apache")
    print("3. Sortir")
    
    opcio = input("Tria una opció (1-3): ")
    
    if opcio == "1":
        print("Executant: df -h (Disc al 45% d'ús)")
    elif opcio == "2":
        print("Executant: systemctl restart apache2... OK")
    elif opcio == "3":
        print("Tancant la sessió d'administració. Adéu!")
    else:
        print("Opció no vàlida. Introdueix 1, 2 o 3.")
```

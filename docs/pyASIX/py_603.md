# Bases de Dades Locals amb SQLite (`#!py import sqlite3`)

Fins ara hem guardat dades en _fitxers de text_, _CSV_ o _JSON_. Aquests formats van bé per a coses senzilles, però si volem fer consultes complexes, filtrar milers de registres o assegurar la integritat de les dades, el millor és utilitzar una **Base de Dades**.

_**SQLite**_ és un sistema de base de dades relacional complet que guarda tota la informació en un únic fitxer de disc (per exemple, `inventari.db`).

## 1. Com funciona la connexió a SQLite?

El flux de treball a Python per treballar amb SQLite consta de 4 passos:

1. **Connectar-nos** al fitxer de la base de dades (`#!py sqlite3.connect()`). Si el fitxer no existeix, Python el crea automàticament.

1. **Crear un Cursor** (`#!py conn.cursor()`), que és l'eina que s'encarrega d'executar les sentències SQL.

1. **Executar comandes SQL** (`#!py cursor.execute()`).

1. **Confirmar els canvis** (`#!py conn.commit()`)

1. **tancar la connexió** (`#!py conn.close()`).

```py
import sqlite3

# 1. Connexió al fitxer de BD (es crearà si no existeix)
conn = sqlite3.connect("xarxa.db")

# 2. Creació del cursor
cursor = conn.cursor()

# 3. Creació d'una taula si no existeix
cursor.execute("""
CREATE TABLE IF NOT EXISTS equips (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    hostname TEXT NOT NULL,
    ip TEXT UNIQUE NOT NULL,
    ram INTEGER
)
""")

# 4. Desar canvis i tancar
conn.commit()
conn.close()
```

## 2. Inserir i Consultar Dades (CRUD Bàsic)

### Inserir dades de forma segura (Paràmetres `?`)

Per evitar atacs d'**Injecció SQL** o errors amb cometes, mai hem de concatenar cadenes de text directament a la sentència SQL. Fem servir el signe d'interrogació `?` com a marcador de posició.

=== "Inserir un sol registre"

    ```python
    import sqlite3
    
    conn = sqlite3.connect("xarxa.db")
    cursor = conn.cursor()

    # Utilitzem '?' i passem les dades com una tupla
    cursor.execute(
        "INSERT INTO equips (hostname, ip, ram) VALUES (?, ?, ?)",
        ("srv-web", "192.168.1.10", 16)
    )

    conn.commit()
    conn.close()
    ```

    !!!question "Quin tipus de dada inserim?"

        En aquest cas el valor inserit el tenim en una **_tupla_**

        ```py
        ("srv-web", "192.168.1.10", 16)
        ```

=== "Inserir múltiples registres (`#!py executemany`)"
    
    ```py
    import sqlite3

    nous_equips = [
        ("srv-db", "192.168.1.20", 32),
        ("srv-proxy", "192.168.1.30", 8),
        ("pc-admin", "192.168.1.100", 16)
    ]

    conn = sqlite3.connect("xarxa.db")
    cursor = conn.cursor()

    cursor.executemany(
        "INSERT INTO equips (hostname, ip, ram) VALUES (?, ?, ?)", 
        nous_equips
    )

    conn.commit()
    conn.close()
    ```

    !!!question "Quin tipus de dada inserim?"

        En aquest cas el valor inserit el tenim en una **_llista de tuples_**

        ```py
        [
            ("srv-db", "192.168.1.20", 32),
            ("srv-proxy", "192.168.1.30", 8),
            ("pc-admin", "192.168.1.100", 16)
        ]
        ```

### Consultar Dades (SELECT)

Per recuperar informació de la base de dades utilitzem `#!py .fetchall()` (obté totes les files com una llista de tuples) o `#!py .fetchone()` (obté només la primera fila).

```py
import sqlite3

conn = sqlite3.connect("xarxa.db")
cursor = conn.cursor()

# Consultem els equips amb més de 8 GB de RAM
# Els paràmetres sempre van com una tupla.
# Si només hi ha un valor, cal posar una coma per indicar que és una tupla. (8,)
cursor.execute("SELECT hostname, ip, ram FROM equips WHERE ram > ?", (8,))
files = cursor.fetchall()

print("=== EQUIPS AMB MÉS DE 8GB RAM ===")
for fila in files:
    # 'fila' és una tupla: (hostname, ip, ram)
    print(f"Servidor: {fila[0]} | IP: {fila[1]} | RAM: {fila[2]} GB")

conn.close()
```

## 3. Gestió d'Errors i Transaccions amb `#!py try...except`

Quan treballem amb bases de dades, els errors són freqüents (per exemple, intentar inserir una IP repetida quan la columna és `_UNIQUE_`).

És molt important fer servir `#!py sqlite3.Error` i la instrucció `#!py conn.rollback()` (per desfer els canvis si alguna cosa falla a meitat del procés).

```py
import sqlite3

try:
    conn = sqlite3.connect("xarxa.db")
    cursor = conn.cursor()

    # Intentem inserir una IP que ja existeix (violarà la restricció UNIQUE)
    cursor.execute(
        "INSERT INTO equips (hostname, ip, ram) VALUES (?, ?, ?)",
        ("srv-duplicat", "192.168.1.10", 8)
    )
    
    conn.commit()
    print("Registre afegit correctament.")

except sqlite3.IntegrityError:
    print(" ERROR: Ja existeix un equip amb aquesta adreça IP a la BD!")
    conn.rollback()  # Desfem qualsevol canvi pendent

except sqlite3.Error as e:
    print(f" ERROR de Base de Dades: {e}")
    conn.rollback()

finally:
    # Aquest bloc s'executa SEMPRE per tancar la connexió de forma segura
    if 'conn' in locals():
        conn.close()
```

## Exercici Pràctic: Registre d'Auditoria d'Usuaris

Crea un script en Python que gestioni una base de dades local anomenada `auditoria.db`.

1. Crea una taula anomenada `incidencies` amb els següents camps:

    * `id` (Enter, Clau primària, Autoincremental)

    * `usuari` (Text, No nul)

    * `accions` (Text, No nul)

    * `nivell_risc` (Enter)

1. Demana per pantalla a l'usuari el seu **nom d'usuari**, l'**acció realitzada** i el **nivell de risc** (de 1 a 5).

1. Intenta inserir aquesta informació a la base de dades. Dins d'un bloc `#!py try...except`, assegura't de capturar qualsevol error d'SQLite.

1. Finalment, fes un `SELECT` que mostri per pantalla totes les incidències registrades que tinguin un nivell de risc superior o igual a 3.

    Pots demanar el nivell de risc a l'usuari, en comptes de fer que sigui el 3.

???example "Possible solució"

    ```py
    import sqlite3

    def inicialitzar_bd():
        """Crea la taula si no existeix"""
        conn = sqlite3.connect("auditoria.db")
        cursor = conn.cursor()
        cursor.execute("""
        CREATE TABLE IF NOT EXISTS incidencies (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            usuari TEXT NOT NULL,
            accions TEXT NOT NULL,
            nivell_risc INTEGER NOT NULL
        )
        """)
        conn.commit()
        conn.close()

    def registrar_incidencia():
        """Demana dades a l'usuari i les insereix a la BD"""
        usuari = input("Nom d'usuari: ")
        accio = input("Acció realitzada: ")
        risc = int(input("Nivell de risc (1-5): "))

        try:
            conn = sqlite3.connect("auditoria.db")
            cursor = conn.cursor()
            
            cursor.execute(
                "INSERT INTO incidencies (usuari, accions, nivell_risc) VALUES (?, ?, ?)",
                (usuari, accio, risc)
            )
            
            conn.commit()
            print(" Incidència registrada amb èxit a la BD.")

        except sqlite3.Error as e:
            print(f" ERROR en registrar a la BD: {e}")
            if 'conn' in locals():
                conn.rollback()
        finally:
            if 'conn' in locals():
                conn.close()

    def mostrar_incidencies_critiques():
        """Mostra les incidències amb risc >= 3"""
        try:
            conn = sqlite3.connect("auditoria.db")
            cursor = conn.cursor()
            
            cursor.execute("SELECT id, usuari, accions, nivell_risc FROM incidencies WHERE nivell_risc >= 3")
            files = cursor.fetchall()

            print("\n=== INCIDÈNCIES CRÍTIQUES (RISC >= 3) ===")
            if not files:
                print("No hi ha cap incidència crítica registrada.")
            else:
                for f in files:
                    print(f"[ID: {f[0]}] Usuari: {f[1]} | Acció: {f[2]} | Risc: {f[3]}")

        except sqlite3.Error as e:
            print(f" ERROR en llegir la BD: {e}")
        finally:
            if 'conn' in locals():
                conn.close()

    # --- Execució del programa ---
    inicialitzar_bd()
    registrar_incidencia()
    mostrar_incidencies_critiques()
    ```

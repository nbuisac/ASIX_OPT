# Diccionaris (`dict`)

Fins ara hem vist estructures de dades com les **Llistes** i les **Tuples**, on accedim als elements mitjançant la seva **_posició numèrica_** (`llista[0]`, `llista[1]`). 

Però, què passa quan volem representar un objecte complex de la realitat? Per exemple, les dades d'un usuari del sistema, la configuració d'una interfície de xarxa o l'estat d'un servidor.

Un **Diccionari** ens permet guardar informació en parelles de **Clau : Valor** (`key : value`). En lloc de recordar quin número de posició ocupa una dada, **hi accedim directament pel seu nom**.

!!! tip "Per què són fonamentals en ASIX?"

    Els diccionaris de Python tenen exactament la mateixa estructura que el format **JSON** (utilitzat en la majoria d'APIs web), les files d'una base de dades **SQLite** i molts fitxers de configuració d'eines com Ansible o Docker.

## 1. Creació d'un Diccionari

Els diccionaris s'escriuen entre **claus** (`{ }`), separant les claus dels valors amb dos punts (`:`) i cada parella amb una coma.

```py
# Dades de configuració d'un servidor
servidor = {
    "hostname": "srv-web-01",
    "ip": "192.168.1.50",
    "port": 80,
    "actiu": True
}
```

* **Claus (_`keys`_)**: Acostumen a ser cadenes de text (`str`) i han de ser úniques.

* **Valors (_`values`_)**: Poden ser de qualsevol tipus de dada: números, text, booleans o fins i tot llistes i altres diccionaris.

## 2. Lectura i Modificació de Dades

Per accedir a un valor o modificar-lo, fem servir el nom de la clau entre corxets (`[ ]`).

```py
# Llegim un valor
print(servidor["hostname"])  # Mostra: srv-web-01
print(servidor["ip"])        # Mostra: 192.168.1.50

# Modifiquem un valor existent
servidor["port"] = 8080

# Afegim una nova parella Clau-Valor
servidor["so"] = "Ubuntu 24.04"

# Esborrem una clau
del servidor["actiu"]
```

!!!warning "Compte amb les claus inexistents!"

    Si intentem accedir a una clau que no existeix (ex: `#!py servidor["ram"]`), Python llençarà un error de tipus _KeyError_ i aturarà l'script.

### Accés segur amb `#!py .get()`

Per evitar que l'script falli si no sabem si una clau existeix, utilitzem el mètode `#!py .get()`. Si la clau no existeix, retorna `#!py None` (o un valor per defecte que definim nosaltres) en lloc de donar un error:

```py
# Accés segur: si no existeix "ram", retorna "No especificat"
ram_servidor = servidor.get("ram", "No especificat")
print(f"RAM: {ram_servidor}")  # Mostra: RAM: No especificat
```

## 3. Recorregut per un Diccionari (`#!py for`)

Hi ha tres maneres principals d'iterar sobre un diccionari segons quina informació necessitem:

=== "1. Recórrer les Claus"

    Per defecte, un bucle `#!py for` sobre un diccionari recull les seves claus:
    ```py
    for clau in servidor:
        print(f"Propietat: {clau} -> Valor: {servidor[clau]}")
    ```

=== "2. Recórrer els Valors (`#!py .values()`)"

    Si només ens interessen els valors i no el nom de les claus:
    
    ```py
    for valor in servidor.values():
        print(f"Valor: {valor}") 
    ```

=== "3. Recórrer Clau i Valor a la vegada (.items())"

    És la manera més habitual i neta (_pythonic_):
    
    ```py
    for clau, valor in servidor.items():
        print(f"{clau.upper()}: {valor}")
    ```

## 4. Estructures Niuades (Llistes de Diccionaris)

A la pràctica real, gairebé mai treballarem amb un sol diccionari. Sovint tindrem una **Llista de Diccionaris** (com quan llegim una taula de la base de dades o una consulta de la xarxa).

```py
# Llista de servidors de la xarxa
inventari = [
    {"hostname": "srv-web", "ip": "10.0.0.1", "ram_gb": 16, "estat": "ok"},
    {"hostname": "srv-db", "ip": "10.0.0.2", "ram_gb": 64, "estat": "error"},
    {"hostname": "srv-backup", "ip": "10.0.0.3", "ram_gb": 8, "estat": "ok"}
]

# Processem la llista de diccionaris
print("=== INFORME D'ESTAT DELS SERVIDORS ===")
for srv in inventari:
    if srv["estat"] == "error":
        print(f" ALERTA: El servidor {srv['hostname']} ({srv['ip']}) té un estat D'ERROR!")
    else:
        print(f" OK: {srv['hostname']} funciona correctament.")
```

# Variables i Tipus de Dades en Sistemes

A l'administració de sistemes utilitzarem Python per _automatitzar tasques_, _llegir fitxers de configuració_ o _processar logs_. Per fer-ho, necessitem guardar informació a la memòria de l'ordinador temporalment utilitzant _**variables**_.

## Què és una Variable?

Podem imaginar una _variable_ com una **caixa amb una etiqueta** (el _nom_) on guardem una dada (el _valor_). En lloc de fer exercicis matemàtics abstractes, en sistemes farem servir variables per desar paràmetres reals de la nostra infraestructura.

```py
# Guardem el nom d'un servidor (String)
hostname = "srv-web-01"

# Guardem el llindar màxim d'alertes de disc (Integer)
max_disk_usage = 90

# Guardem el percentatge de memòria lliure actual (Float)
ram_free_pct = 14.5
```

## Tipats en Python

Com ja sabem per la introducció, _Python_ té tipat _dinàmic_ i _fort_. Això té implicacions directes quan gestionem dades de sistemes:

* _**Tipat dinàmic**_: Una variable pot canviar de tipus si li assignem un nou valor.

* _**Tipat fort**_: No podem barrejar tipus directament (per exemple, sumar un text i un número).

Tipus de dades bàsics que farem servir:

* _**Strings**_ (_Text_) `(str)`: Per rutes de fitxers, IPs, comandes o usuaris. Es defineixen entre cometes (`"` o `'`).

* _**Integers**_ (_Enters_) `(int)`: Per a IDs de processos (PID), ports de xarxa o mides en bytes.

* _**Floats**_ (_Decimals_) `(float)`: Per a mitjanes de càrrega de la CPU (load average), temps de resposta de xarxa, etc.

* _**Booleans**_ (_True_/_False_) `(bool)`: Per comprovar estats o si un servei s'està executant.

!!!danger "Exemple d'error típic de SysAdmin (Tipat Fort)"

    Imagineu que llegim un fitxer de configuració on hi ha el port d'un servidor web, o intentem muntar una alerta:

    ```py hl_lines="5"
    port_text = "80"  # És un text (String) perquè va entre cometes
    port_numeric = 80 # És un número (Integer)

    # Això donarà un ERROR (TypeError) si intentem sumar-ho:
    print("El següent port és el: " + port_numeric)
    ```

    Per arreglar-ho, hem de fer una conversió explícita (_casting_), que veurem molt sovint en rebre dades del sistema:

    ```py hl_lines="5"
    # Convertir un número a text per imprimir un log:
    print("El servei escolta pel port: " + str(port_numeric))

    # Convertir un text rebut a número per poder operar (ex: comprovar si és el port 80):
    if int(port_text) == 80:
        print("És el protocol HTTP")
    ```

## [Bones pràctiques en els noms de variables (Estil *SysAdmin*)][naming]

Perquè els scripts siguin llegibles per a altres administradors, utilitzarem el format [_**`snake_case`**_][snake_case] (tot en minúscules i separat per guions baixos) i _noms autoexplicatius_:

| Nom Incorrecte / Poc clar | Nom Correcte (SysAdmin Style) |
|:--------------------------|:------------------------------|
| `x = "/var/log/nginx"` | `log_dir = "/var/log/nginx"` |
| `ip = "192.168.1.1"` | `gateway_ip = "192.168.1.1"` |
| `comptador = 4` | `active_connections = 4` |
| `status = True` | `is_ssh_enabled = True` |

[naming]:       https://peps.python.org/pep-0008/#naming-conventions
[snake_case]:   https://ca.wikipedia.org/wiki/Snake_case

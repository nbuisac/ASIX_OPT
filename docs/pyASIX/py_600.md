# Gestió d'Errors i Excepcions ([`#!py try ... except`][try])

Fins ara hem assumit que els nostres scripts sempre trobaran els fitxers a la ruta correcta i amb el format esperat. Però al món real (i especialment en l'administració de sistemes), **els fitxers poden no existir, no tenir permisos o estar corromputs**.

Si Python troba un error que no sap gestionar, atura l'execució immediatament i mostra un error crític (_Traceback_). Per evitar que els nostres scripts fallin de cop, utilitzem el bloc [`#!py try ... except`][try].

## 1. La sintaxi bàsica

Pensem en el bloc [`#!py try`][try] com un "_posa a prova aquest codi_" i l'[`#!py except`][except] com la "_xarxa de seguretat_".

```py
try:
    # Codi que pot generar un error
    with open("configuracio.txt", "r", encoding="utf-8") as f:
        contingut = f.read()
    print("Fitxer llegit amb èxit!")

except FileNotFoundError:
    # Codi que s'executa NOMÉS si el fitxer no existeix
    print(" ERROR: El fitxer 'configuracio.txt' no s'ha trobat al disc.")
```

Si el fitxer existeix, s'executa el bloc `#!py try` i se salta l'`#!py except`. Si el fitxer no existeix, Python salta immediatament a l'`#!py except` sense aturar el programa.

## 2. Capturem diferents tipus d'errors (_Excepcions_)

En la gestió de fitxers hi ha diferents motius pels quals un script pot fallar. Podem afegir tants blocs except com tipus d'errors vulguem controlar:

| Excepció Comuna | Quan es produeix? |
|:----------------|:------------------|
| `#!py FileNotFoundError` | Intentem llegir un fitxer que no existeix a la ruta especificada. |
| `#!py PermissionError` | L'usuari del sistema no té permisos suficients (lectura/escriptura). |
| `#!py json.JSONDecodeError` | El fitxer JSON existeix però té un error de sintaxi i no es pot carregar. |
| `#!py Exception` | Qualsevol altre error genèric (funciona com un "_comodí_"). |

**Exemple complet d'auditoria:**

```py title="Exemple complet d'auditoria"
import json

try:
    with open("dades.json", "r", encoding="utf-8") as f:
        dades = json.load(f)
    print("Dades carregades correctament.")
except FileNotFoundError:
    print(" ERROR: No s'ha trobat el fitxer 'dades.json'.")
except PermissionError:
    print(" ERROR: No tens permisos de lectura sobre aquest fitxer.")
except json.JSONDecodeError:
    print(" ERROR: El fitxer existeix però NO té un format JSON vàlid!")
except Exception as e:
    # Captura qualsevol altre error inesperat i guarda el missatge original
    print(f" ERROR INESPERAT: {e}")
```

## 3. L'estructura completa: [`#!py else`][else] i [`#!py finally`][finally] (Opcional)

Per a scripts d'alta disponibilitat o gestió de recursos, podem afegir dos blocs més:

* **[`#!py else`][else]**: S'executa només si NO hi ha hagut cap error al `#!py try`.

* **[`#!py finally`][finally]**: S'executa **SEMPRE**, hagi anat bé o hi hagi hagut un error (ideal per tancar connexions, netejar fitxers temporals, etc.).

```py
try:
    f = open("log.txt", "r")
except FileNotFoundError:
    print("El fitxer no existeix.")
else:
    print("S'ha llegit el fitxer correctament!")
    f.close()
finally:
    print("Fi del procés de verificació.")
```

## Exercici Pràctic: Robustesa en la Lectura de Logs

Fes un script que demani a l'usuari la ruta d'un fitxer de log per pantalla.

L'script ha d'intentar obrir el fitxer i comptar quantes línies té.

* Si el fitxer no existeix (`#!py FileNotFoundError`), ha de mostrar: "_`L'arxiu indicat no existeix.`_"

* Si la ruta és un directori i no un fitxer (`#!py IsADirectoryError` o `#!py PermissionError`), ha de mostrar: "_`No es pot llegir: No tens permisos o és un directori.`_"

* En qualsevol d'aquests dos casos d'error, el programa ha de tornar a demanar la ruta a l'usuari fins que en posi una de vàlida (fent servir un bucle `#!py while`).

???example "Possible Solució"

    ```py
    correcte = False

    while not correcte:
        ruta = input("Introdueix la ruta del fitxer de log a analitzar: ")
        
        try:
            with open(ruta, "r", encoding="utf-8") as f:
                linies = f.readlines()
                
            print(f" Accés correcte! El fitxer té {len(linies)} línies.")
            correcte = True  # Permet sortir del bucle while
            
        except FileNotFoundError:
            print(" ERROR: L'arxiu indicat no existeix. Torna-ho a provar.\n")
            
        except (PermissionError, IsADirectoryError):
            print(" ERROR: No es pot llegir la ruta (és un directori o no tens permisos).\n")
            
        except Exception as e:
            print(f" ERROR INESPERAT ({e}). Torna-ho a provar.\n")
    ```

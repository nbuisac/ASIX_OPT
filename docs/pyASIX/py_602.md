# Formats d'Intercanvi de Dades ([.json][json] i [.xml][xml])

Quan enviem o rebem informació a través d'internet (consultant la _REST API_ d'un servidor, un servei web o un fitxer de configuració d'eines com _Docker_ o _Ansible_), les dades poques vegades viatgen en _text pla_ o _CSV_. S'utilitzen formats d'intercanvi de dades.

En aquest apartat veurem els dos formats estructurats més utilitzats: _JSON_ (el més popular i modern) i _XML_ (molt utilitzat en entorns corporatius i serveis web clàssics).

## 1. El Format JSON ([`#!py import json`][json])

El format _JSON_ (_JavaScript Object Notation_) és el rei absolut de l'intercanvi de dades a la web actual.

La gran notícia per a nosaltres és que la sintaxi de _JSON_ és pràcticament idèntica a la dels _Diccionaris_ i _Llistes_ de Python.

| Concepte JSON | Equivaleix a Python |
|:--------------|:--------------------|
| Objecte `#!py { "clau": "valor" }` | Diccionari `#!py dict` |
| Matriu/Llista `#!py [ 1 |  2 |  3 ]` | Llista `#!py list` |
| Text `#!py "Hola"` | Cadena de text `#!py str` |
| Booleà `#!py true` / `#!py false` | Booleà `#!py True` / `#!py False` |
| Nul `#!py null` | Valor `#!py nul` `#!py None` |

Per treballar amb JSON a Python fem servir la llibreria oficial [`json`][json]:

```py
import json
```

### Lectura i Escriptura de fitxers JSON

Treballar amb fitxers [`#!py .json`][json] és tan senzill com convertir el fitxer directament en un _Diccionari_ de Python:

=== "Llegir un fitxer JSON (`#!py json.load`)"

    El mètode `#!py json.load()` llegeix el fitxer i el transforma automàticament en un diccionari o una llista de Python.
    
    ```py
    import json
    # Llegir configuració d'una aplicació
    with open("config.json", "r", encoding="utf-8") as f:
        config = json.load(f)

    # 'config' ja és un diccionari normal de Python!
    print(f"Servidor: {config['server_name']}")
    print(f"Port: {config['port']}")
    ```

=== "Escriure un fitxer JSON (`#!py json.dump`)"
    
    El mètode `#!py json.dump()` agafa un diccionari o llista de Python i el guarda en format JSON dins del fitxer.
    
    ```py
    import json
    dades_servidor = {
        "hostname": "srv-db-01",
        "ip": "10.0.0.15",
        "serveis": ["mysql", "redis"],
        "actiu": True
    }

    with open("estat_servidor.json", "w", encoding="utf-8") as f:
        # indent=4 fa que el fitxer s'escrigui bonic i llegible
        json.dump(dades_servidor, f, indent=4)

    print("Fitxer JSON creat amb èxit!")
    ```

!!! tip "Com convalidar text JSON directament (loads / dumps)"

    Si en lloc d'un fitxer tenim el JSON contingut en una variable de text (per exemple, la resposta d'un lloc web), fem servir `#!py json.loads()` (load string) per passar de text a diccionari, i `#!py json.dumps()` per passar de diccionari a text.

## 2. El Format [XML][xml] ([`#!py import xml.etree.ElementTree`][ElementTree])

El format _XML_ (_eXtensible Markup Language_) utilitza etiquetes amb obertura i tancament similars a l'HTML (<etiqueta>contingut</etiqueta>). Forma una estructura en arbre on hi ha un node arrel (root) del qual pengen la resta d'elements.

Exemple de fitxer `usuaris.xml`:

```xml title="usuaris.xml"
<sistema>
    <usuari id="1">
        <nom>root</nom>
        <shell>/bin/bash</shell>
    </usuari>
    <usuari id="2">
        <nom>marta</nom>
        <shell>/bin/zsh</shell>
    </usuari>
</sistema>
```

Per llegir i analitzar (parsejar) fitxers _XML_ a _Python_, la forma més senzilla i oficial és el mòdul [`ElementTree`][ElementTree]:

```py
import xml.etree.ElementTree as ET
```

### Lectura de fitxers [XML][xml]

```py
import xml.etree.ElementTree as ET

# 1. Carreguem i analitzem el fitxer XML
tree = ET.parse("usuaris.xml")
root = tree.getroot()  # Obtenim l'element arrel (<sistema>)

print(f"Node arrel: {root.tag}")  # Mostra: sistema

# 2. Recorrem els nodes fills amb un bucle 'for'
for usuari in root.findall("usuari"):
    # Accedim als atributs de l'etiqueta (ex: id="1")
    uid = usuari.attrib.get("id")
    
    # Accedim al text interior de les sub-etiquetes amb .find().text
    nom = usuari.find("nom").text
    shell = usuari.find("shell").text
    
    print(f"ID: {uid} | Usuari: {nom} | Shell: {shell}")
```

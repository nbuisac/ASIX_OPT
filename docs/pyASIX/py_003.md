# Entrada de dades: Parlant amb els nostres programes

Fins ara hem creat scripts on tota la informació estava escrita directament dins del codi (per exemple, `nom = "Joan"`). Però un bon programa ha de ser capaç de demanar informació a la persona que l'està utilitzant en cada moment.

Per fer que el nostre script de Python s'aturi i ens demani que escrivim alguna cosa des de la terminal, utilitzarem la funció [`input()`][input()].

## 1. Com funciona [`input()`][input()]?

Quan Python es troba la instrucció [`input()`][input()], el programa es frena i es queda esperant que l'usuari escrigui el text que vulgui pel teclat i premi la tecla <kbd>Intro</kbd>.

Mireu aquest exemple elemental:

```py
# El programa fa una pregunta i guarda el que l'usuari escrigui dins la variable
nom_usuari = input("Com et dius?: ")

# Ara saludem fent servir la informació que ens acaben de donar
print("Hola, " + nom_usuari + ". Benvingut/da a la terminal.")
```

Si proveu d'executar aquest script, veureu que la línia on diu __`Com et dius?:`__ es queda parpellejant fins que hi escriviu alguna cosa.

## 2. El gran secret de [`input()`][input()]: Tot és text!

Això és el que més us farà ballar el cap al principi. No importa el que escriviu a la pantalla; per a Python, tot el que entra a través d'un [`input()`][input()] és un text (_String_).

Imagineu que voleu fer un script que demani quantes carpetes volem crear avui al disc dur:

```py
# Demanem el número de carpetes
carpetes = input("Quantes carpetes vols crear?: ")

# Imaginem que l'alumne escriu el número: 3
# Per a Python, la variable 'carpetes' no val el número 3. Vale el text "3" (amb cometes).
```

!!!tip "Per a Python, la variable 'carpetes' no val el número 3. Vale el text "3" (amb cometes)."

    I com que és un text, no el podem tractar com un número sumant-li valors (o restant-los) ni comparant-los amb altres números.

### Què passa si intentem operar amb aquest "text"?

Si intentem sumar-li un número o fer una operació matemàtica (com calcular quantes carpetes tindrem si en creem dues més), el programa fallarà amb un error de tipus (_`TypeError`_), perquè Python no sap sumar lletres amb números reals.

```py title="AIXÒ DONARÀ UN ERROR"
total = carpetes + 2
```

## 3. La solució: Transformar el text en números (Casting)

Per sort, podem dir-li a Python que agafi el text que ha escrit l'alumne i el converteixi en un número enter de veritat per poder fer càlculs. Això ho fem col·locant la funció [`int()`][int()] al voltant del nostre [`input()`][input()]:

```py
# Convertim l'entrada directament en un número enter (Integer)
quantitat_fitxers = int(input("Quants fitxers vols esborrar?: "))

# Ara que és un número, podem calcular el doble si cal!
doble = quantitat_fitxers * 2
print("Si continuem així, n'esborrarem:")
print(doble)
```

### I per números decimals?

Per números decimals tenim la funció [`float()`][float()] que la utilitzarem igual que l'anterior [`int()`][int()].

```py
# Convertim l'entrada directament en un número amb decimals (Float)
preu_ordinador = float(input("Quant t'ha costat l'ordinador?: "))

# Ara que és un número, podem calcular el doble si cal!
preu_sense_iva = preu_ordinador / 1.21
print("El reu sense IVA ha estat:", preu_sense_iva)
```

!!!info "Regla d'or: Si el que demanem a l'usuari és..."

    * **una paraula** o **un nom**, utilitzarem `input()` a seques. 
    
    * **un número enter** per fer càlculs o comptar coses, utilitzarem `int(input())`.

    * **un número amb decimals** per fer càlculs, utilitzarem `float(input())`.

## 4. Pràctica guiada: El generador de rutes

Anem a fer un script molt senzill que ens ajudi a saber on guardarem les dades d'un usuari nou a l'ordinador. Només demanarem paraules, així que no ens cal fer conversions.

```py
print("--- CONFIGURADOR DE DIRECTORIS DE L'ALUMNE ---")

# Demanem les dades de l'alumne
nom = input("Introdueix el nom de l'estudiant: ")
curs = input("Introdueix el curs (ex: ASIX1, ASIX2, DAM1, DAM2, DAW1, DAW2): ")

# Ajuntem el text per simular la ruta de la seva carpeta de pràctiques
ruta_final = "/home/alumnes/" + curs + "/" + nom

print("La carpeta d'aquest alumne es crearà a:")
print(ruta_final)
```

!!!tip "Podem sumar cadenes de caràcters"

    **Sí**, en el cas de les cadenes de caràcters, l'operador **`+`**, **_concatena_** els diferents valors.

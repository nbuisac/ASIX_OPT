# Funcions i Modularitat (`#!py def`)

Fins ara hem escrit scripts on el codi s'executa de dalt a baix. Però quan els nostres programes creixen, repetir el mateix codi una vegada i una altra el fa difícil de llegir i mantenir.

Una funció és un bloc de codi reutilitzable al qual li posem un nom. Només s'executa quan el "cridem".

## 1. Definim i cridem una funció bàsica

Utilitzem la paraula clau `#!py def` per crear una funció i parèntesis `#!py ()` per indicar els paràmetres que rep.

```py
# 1. Definició de la funció (no s'executa immediatament, només es guarda en memòria)
def saludar_servidor():
    print(" Connectant amb el servidor central...")
    print(" Autenticació correcta.")

# 2. Cridada a la funció (aquí és quan s'executa)
saludar_servidor()
saludar_servidor()  # La podem cridar quantes vegades vulguem!
```

## 2. Passem dades a la funció: Paràmetres

Podem enviar informació a la funció perquè faci càlculs o accions dinàmiques:

```py
def comprovar_espai_disc(directori, percentatge_usat):
    print(f"Analitzant la ruta: {directori}")
    if percentatge_usat > 90:
        print(f" ALERTA CRÍTICA: Disc ple al {percentatge_usat}%!")
    else:
        print(f" Espai correcte ({percentatge_usat}% usat).")

# Executem passant diferents arguments:
comprovar_espai_disc("/var/log", 95)
comprovar_espai_disc("/home", 45)
```

## 3. Retornem valors amb return

La majoria de funcions no només mostren text per pantalla amb print(), sinó que calculen o processen una dada i la retornen al programa principal utilitzant la instrucció return.

```py
def calcular_ram_lliure(total_ram, ram_usada):
    lliure = total_ram - ram_usada
    return lliure  # Retorna el resultat al codi que ha cridat la funció

# Guardem el resultat que ens torna la funció en una variable:
ram_restant = calcular_ram_lliure(16, 11)
print(f"Queden {ram_restant} GB de RAM lliures al servidor.")
```

!!! warning "Diferència clau entre print() i return"

    * `#!py print()` només mostra un text per la pantalla (terminal), però la dada es perd.

    * `#!py return` envia el resultat de tornada al programa per poder-lo **guardar en una variable**, **utilitzar-lo en un `#!py if`** o **guardar-lo en un fitxer**.

# Iteracions (Bucles `#!py for` amb Llistes i `#!py range`)

Fins ara, per accedir als elements d'una llista havíem de posar l'índex manualment (`#!py llista[0]`, `#!py llista[1]`, etc.). Però si tenim una llista de 100 usuaris o servidors, no podem escriure 100 línies de codi.

Per això utilitzem el bucle [`#!py for:`][for] una estructura que ens permet repetir un bloc de codi per a cada element d'una col·lecció de dades.

## 1. Recórrer una Llista Element per Element amb [`#!py for()`][for]

Aquesta és la manera més directa i llegible. Es llegeix literalment com:

"_**Per a cada element de la llista, fes això**_".

```py 
servidors = ["srv-web", "srv-db", "srv-backup"]

# La variable 'servidor' anirà agafant el valor de cada element a cada iteració
for servidor in servidors:
    print(f"Comprovant estat de: {servidor}")
    print("----------------------------")
```

**Sortida per pantalla**

```txt
Comprovant estat de: srv-web
----------------------------
Comprovant estat de: srv-db
----------------------------
Comprovant estat de: srv-backup
----------------------------
```

!!!tip "Recorda la indentació (els 4 espais de sangria)."

    Tot el que estigui indentat dins del `#!py for` s'executarà una vegada per cada element.

## 2. La Funció [`#!py range()`][range]: Generar Seqüències de Números

Quan volem repetir una acció un número concret de vegades, utilitzem la funció [`#!py range()`][range].

La funció `#!py range(inici, final, pas)` genera una seqüència numèrica:

* range(5) $\rightarrow$ Genera números del 0 al 4 (el número final mai s'inclou!).

* range(1, 6) $\rightarrow$ Genera números del 1 al 5.

* range(0, 10, 2) $\rightarrow$ Genera del 0 al 8 de 2 en 2 (0, 2, 4, 6, 8).

Exemple d'ús bàsic amb `#!py for`:

```py
print("Iniciant el compte enrere...")

for segons in range(5, 0, -1):
    print(f"Reiniciant el servidor en {segons} segons...")

print(" Servidor reiniciat!")
```

## 3. Combinar `#!py range()` i `#!py len()` per recórrer per Posició (Índex)

A vegades necessitem saber no només l'element, sinó quina posició (índex) ocupa dins la llista. Per fer-ho, combinem `#!py range()` i `#!py len()`:

```py
usuaris = ["marta", "pau", "laura"]

# len(usuaris) és 3 -> range(3) generarà 0, 1, 2 (les posicions de la llista!)
for i in range(len(usuaris)):
    print(f"Usuari núm. {i + 1}: {usuaris[i]}") # Estem accedint als elements per la posició que ocupen
```

**Sortida per pantalla:**

```txt
Usuari núm. 1: marta
Usuari núm. 2: pau
Usuari núm. 3: laura
```
